# habit-hooks Homebrew tap

Structural code-smell coaching for AI agents.

```sh
brew install habit-hooks/tap/habit-hooks
```

This installs the core and all four plugins — `generic`, `python`, `typescript`
and `php` — so there is nothing to add by hand. Enable the ones you want in your
project's `.habit-hooks/config.toml`, or let `habit-hooks init` work it out and
write it for you.

Project: https://github.com/habit-hooks/habit-hooks
