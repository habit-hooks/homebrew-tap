# habit-hooks Homebrew tap

Structural code-smell coaching for AI agents.

```sh
brew install habit-hooks/tap/habit-hooks
```

This installs the core plus the language-agnostic `generic` plugin. Language
plugins are opt-in via the PyPI extras (`habit-hooks[python]`, `[typescript]`,
`[php]`, `[all]`) — install those with `uv`/`pipx`/`pip`.

Project: https://github.com/habit-hooks/habit-hooks
